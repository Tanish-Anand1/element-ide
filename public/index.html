CONNECT YOUR BROWSER

Use the browser
you are signed into.

Load the project’s extension folder as an unpacked extension. Open the page you want to edit and click Element in the browser toolbar. The Elements workspace opens beside that exact tab and connects automatically.

The extension asks for Chrome’s debugger permission because that API can inspect and mutate the selected tab. Chrome displays a debugging banner while it is attached.

Use an isolated debugging browser instead

Launch a separate Chrome, Edge, Brave, Vivaldi or Chromium profile:

npm run browser

Refresh the tab list here and connect.

The extension works with Chromium browsers. Browser settings pages cannot be inspected. Firefox and Safari need separate adapters. Reloading or navigating clears edits and undo history.
